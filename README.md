# AgenciaViaje
Este es un sistema web desarrollado en PHP y MySQL que permite registrar vuelos, hoteles y realizar reservas que vinculan a ambos. El proyecto incluye control de sesión, formularios dinámicos y visualización de datos.

# Funciones
La idea de esta página web es que permita las funciones que se necesitarían en una agencia de viajes, como buscar vuelos, realizar reservas, considerar la fecha actual para no reservar en una fecha anterior, crear formularios que permitan almacenar datos relavantes para las reservas, etc.
Otr función relevante es la creación de un carrito de compras que sea capaz de tener una sessión con límite de tiempo y que pueda sumar los paquetes.
